First public release of `ui-to-hierarchyMCP` — an MCP (Model Context Protocol) server that parses a Next.js App Router codebase and returns its UI component hierarchy as structured output (markdown tree + JSON).

Available on npm as **[`ui-hierarchy-mcp`](https://www.npmjs.com/package/ui-hierarchy-mcp)**.

## Install

```json
{
  "mcpServers": {
    "ui-hierarchy": {
      "command": "npx",
      "args": ["-y", "ui-hierarchy-mcp"]
    }
  }
}
```

Add to `~/.claude.json` (Claude Code), `~/.cursor/mcp.json` (Cursor), or your MCP client config.

## Tools

- `get_full_hierarchy` — ordered layout chain + page subtree for a Next.js App Router route
- `focus_on` — subtree rooted at a named JSX component, optionally with ancestors
- `find_by_text` — find nodes by rendered text content (returns file:line)
- `find_by_style` — find nodes by CSS class name or style prop (returns file:line)

## Tech

- TypeScript + `@modelcontextprotocol/sdk` v1.29
- `@babel/parser` + `@babel/traverse` for JSX/TSX AST analysis
- `get-tsconfig` for tsconfig path-alias resolution
- ESM-only, Node `>=20`, MIT license

## Scope

V1 covers Next.js App Router. Pluggable internal architecture for future framework parsers (React Native, Vue, Svelte). Caching, watch mode, and HTTP transport are explicitly deferred to v2.
