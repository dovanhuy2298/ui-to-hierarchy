## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user shell → CLI argv | User-controlled `process.argv` enters parseArgs untrusted |
| build tooling → bundle | `package.json` version string is substituted into a string constant at build time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | `--target` argv value | mitigate | parseArgs strict mode rejects unknown flags; secondary enum check against `VALID_TARGET_IDS` in parseInitArgs rejects unknown tokens before any file write happens downstream (INIT-03) |
| T-07-02 | Information Disclosure | error messages echo invalid target token to stderr later | accept | Echoing the user-supplied token back is required UX for INIT-03 acceptance; not sensitive data |
| T-07-03 | Tampering | `pkg.version` substituted into `__INIT_MARKER_VERSION__` | accept | Source is local package.json, read at build time only; not user-controlled at runtime |
| T-07-04 | Denial of Service | unbounded `--target` string length | accept | Single argv string parsed by Node parseArgs; existing OS-level argv limits apply |
</threat_model>
