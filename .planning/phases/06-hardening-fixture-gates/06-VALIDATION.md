## Sampling Rate

- **After every task commit:** Run `pnpm test:integration` (whole integration suite — tolerable on Windows).
- **After every plan wave:** Run `pnpm test && pnpm test:integration && pnpm test:smoke` (full project test surface).
- **Before `/gsd-verify-work`:** Full suite green + `06-UAT.md` PASS grid filled + `06-PERF.md` populated + `uat-evidence/` non-empty.
- **Max feedback latency:** ~20 seconds (integration alone).
