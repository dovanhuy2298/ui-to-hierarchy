**Windows path gate** (NEW pattern — no analog; built from `EnvelopeSchema` + `TreeNode` discriminated union from `src/ir/schema.ts` lines 12-79):
```typescript
function walkTreeNodes(node: TreeNode, fn: (n: TreeNode) => void): void {
  fn(node);
  if ("children" in node && Array.isArray(node.children)) {
    for (const c of node.children) walkTreeNodes(c, fn);
  }
  if (node.kind === "branch") {
    if (node.thenBranch) walkTreeNodes(node.thenBranch, fn);
    if (node.elseBranch) walkTreeNodes(node.elseBranch, fn);
  }
  if (node.kind === "list") walkTreeNodes(node.item, fn);
}

it("Windows path gate: every file field is forward-slash only", () => {
  for (const env of allEnvelopes) {
    walkTreeNodes((env as Envelope).tree, (node) => {
      expect(node.file, `backslash leak in ${node.file}`).toMatch(/^[^\\]*$/);
    });
    // Defense in depth (CONTEXT.md discretion):
    expect(JSON.stringify(env).match(/\\\\/), "envelope contains backslash").toBeNull();
  }
});
```
The walker covers all 9 `TreeNode` kinds (`component`, `element`, `text`, `branch`, `list`, `slot`, `error`, `fragment`, `spread`) — `branch` recurses into `thenBranch`/`elseBranch`, `list` recurses into `item`, the rest carry `children?: TreeNode[]`.
