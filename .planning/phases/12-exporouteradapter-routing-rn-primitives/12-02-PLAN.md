`ExpoSegment` discriminated union (locked by D-11 + SPEC Req 3 acceptance): uses field name `name` (NOT `param`). Variants: `static`, `dynamic`, `catch-all`, `optional-catch-all`, `group`, `index` (no name field), `special`. Exact shape and regexes are documented in 12-PATTERNS.md "src/adapters/expo/segments.ts" section.

`resolveExpoRoot` priority order is `["src/app", "app"]` — REVERSED from Next.js's `["app", "src/app"]` per D-08. Both candidates checked with `fs/promises.access`; first hit wins; both missing → `null`.

`discoverEntries` glob: pattern `["**/*.{tsx,jsx,ts,js}"]`, ignore `["**/components/**", "**/hooks/**", "**/utils/**", "**/node_modules/**"]`, `absolute: true`, `dot: false`. Result mapped through `toForwardSlash` and lex-sorted (`(a, b) => (a < b ? -1 : a > b ? 1 : 0)`). NEVER ignore `(*)` group folders.

`RouteMatch` type (from `src/adapters/types.ts`): `{ matched: boolean, entries: string[], params: Record<string,string>, slots: Record<string,string> }`. `cloneEmpty()` helper returns `{ matched: false, entries: [], params: {}, slots: {} }` (verbatim from Next.js `route-map.ts` lines 57–59).

`RN_PRIMITIVES` allowlist (SPEC Req 9 — exact members): `View, Text, ScrollView, Image, Pressable, TouchableOpacity, TouchableHighlight, TouchableWithoutFeedback, FlatList, SectionList, Modal, KeyboardAvoidingView, SafeAreaView`.

Warning channel for dual-root detection: D-08 + RESEARCH.md Pattern 3 + Pitfall 4 mandate instance-level `pendingWarnings: string[]` on `ExpoRouterAdapter` (NOT in this plan's files — only the wiring contract). The standalone `discoverEntries` in `discover.ts` MUST NOT mutate global state and MUST NOT call `console.*`. The dual-root detection is delegated to a separate exported helper `detectDualRoots(absRoot): Promise<{ hasSrcApp: boolean, hasApp: boolean }>` so that `ExpoRouterAdapter.discoverEntries` (Wave 2) can call it, push into `pendingWarnings`, and then call the standalone `discoverEntries`.

`toForwardSlash` is imported from `../../core/paths.js` and MUST be applied to every emitted path string.
